# Portfolio fonts

Vendored from the published Fontsource packages, with their SIL Open Font License files alongside them:

- `@fontsource-variable/inter` 5.3.0: `inter-latin-wght-normal.woff2` (normal, weight axis 100–900).
- `@fontsource/cormorant-garamond` 5.3.0: `cormorant-garamond-latin-500-italic.woff2` (italic, weight 500).

These are the existing design typefaces. Vite fingerprints the files and serves them with the site; no runtime font-provider request or package dependency is required. Keep the licenses when updating the assets. Other scripts/characters use the existing system fallback stack.
